# 01 · 项目上下文

- 产品：AudioText Desktop，本地离线"音视频转文字"桌面应用（Windows 10/11 x64）。
- 前端壳：Electron（生态成熟、热门）。
- 用户：需要频繁把录音/录屏/通话转文字的个人（求职、会议、内容创作等）。
- 核心价值：隐私（不上传）、离线、双击即用、一键复制去外部 AI 总结。
- 边界：一期**不做**内置 AI 总结/问答、云账号、说话人分离、翻译、视频编辑。
- 关键决策：本地推理；faster-whisper + CTranslate2；`device=auto`；**无模型安装包 + 三模型离线包或应用内主动下载（魔搭）**；默认输出 `txt`（无时间戳）+`srt`。

权威来源：`docs/PRD.md`（范围/验收）、`docs/design.md`（技术设计）。
