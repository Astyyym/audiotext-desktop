# PRD · 音视频转文字桌面工具

> 本文件是**产品范围与验收的唯一权威**。与其它文档冲突时以本文件为准。

## 1. 背景与问题
工作中有大量音视频（面试录音、会议录屏、电话沟通、培训视频）需要转成文字用于复盘、检索、交给 AI 总结。人工整理耗时、易漏。需要一个本地、离线、双击即用的桌面工具。

## 2. 目标
- 把音视频转成高质量中文文字稿，可选时间戳。
- 完全本地推理、隐私安全，不上传音视频；仅用户主动下载模型时联网。
- 产出可一键**复制**，方便粘贴到网页 AI 做总结。
- 安装简单：**无模型安装包 + 按需模型**。small、medium、large-v3 默认均不打包；安装后在模型页从魔搭下载，或导入独立三模型压缩包。至少准备一个模型后即可转写。
- 覆盖不同性能机器：有独显用 GPU，无独显自动回落 CPU。

## 3. 目标用户
需要频繁把音视频文字化的个人：求职者、会议记录者、内容创作者、行政/研究岗位等。

## 4. 范围与非目标
**In scope（一期）**：音视频→文字（含/不含时间戳）、批量队列、进度、断点、可选术语校正、导出 `txt/srt/md/json`、一键复制、硬件自适应档位。

**Out of scope（一期不做）**：
- 内置 AI 总结 / 问答（交给外部网页 AI）；
- 云端账号、同步、计费；
- 说话人分离、翻译、视频编辑。

## 5. 功能需求
| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-1 | 拖拽/选择多个音视频；支持 m4a/mp4/mov/wav/mp3/aac/flac/mkv/webm/amr/opus/wma/3gp | P0 |
| FR-2 | 语言选择（中文为主，可选自动识别/英文） | P0 |
| FR-3 | 设备档位：自动 / GPU 质量优先 / CPU 速度优先 | P0 |
| FR-4 | 模型档位：large-v3 / medium / small（按已安装模型显示） | P0 |
| FR-5 | 实时进度（已转写时长/总时长）与剩余时间估计 | P0 |
| FR-6 | 产出 `txt`（纯文本、无时间戳）并支持「复制全文」 | P0 |
| FR-7 | 产出 `srt`；可选 `md`（带 [mm:ss]）与 `json`（结构化） | P1 |
| FR-8 | 批量队列、失败重试、断点续跑（同名输出跳过） | P1 |
| FR-9 | 可选术语表校正（auto / context / review） | P2 |
| FR-10 | 输出目录选择；命名冲突自动加序号 | P1 |
| FR-11 | 元信息展示：时长、模型、语言、耗时、实时倍率、字符数 | P2 |

> 输出文件的格式细节（编码、示例、命名）见 `docs/design.md` 的「输出规范」，不在此重复定义。

## 6. 非功能需求
- **离线**：转写使用本地模型、不上传音视频；模型页仅在用户主动点击下载时连接魔搭。
- **隐私**：临时音频处理完即删除。
- **兼容**：Windows 10/11 x64（后续可扩展 macOS/Linux）。
- **易用**：安装后双击即用，不要求用户装 Python/CUDA Toolkit（NVIDIA 驱动除外）。
- **健壮**：单文件失败不影响其它任务；异常有清晰提示。
- **性能**：GPU（RTX 4060 级）≥15× 实时；CPU 模式 ≤0.5× 实时（small）。
- **体积**：无模型安装器目标 <1 GiB；模型独立按需下载或离线导入，GitHub Release 只分发程序安装器及校验文件。

## 7. 已确认决策
| 决策 | 结论 |
|---|---|
| 推理位置 | 本地离线 |
| 主引擎 | faster-whisper + CTranslate2 |
| 低配方案 | 同引擎 `device=cpu, int8`（二期再加 whisper.cpp/OpenVINO 覆盖核显） |
| 分发形态 | 无模型安装包（引擎 + ffmpeg + CUDA）；三模型独立 ZIP 或模型页主动从魔搭下载 |
| 默认输出 | `txt`（无时间戳）+ `srt`；`md/json` 可选 |
| 总结能力 | 一期不做，复制给外部网页 AI |
| 应用名称 | AudioText Desktop |
| 前端壳 | Electron（生态成熟、热门） |

## 8. 验收标准（示例）
- 15 分钟中文录音，GPU 模式输出 `txt` 内容可读、无大段漏句，耗时 <2 分钟。
- 无独显机器切 CPU 模式可正常出稿。
- `txt` 复制到任意网页 AI 可正常粘贴、无乱码（UTF-8）。
